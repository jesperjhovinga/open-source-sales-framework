# Tone of Voice — Example-Corp

## Language
- Default language: **English (US)** for all channels.
- (This is where a Dutch org would set `nl` per channel — language is an org
  value, never a framework rule.)

## Voice patterns (all channels)
1. Plain talk, contractor-respectful. Write like someone who has stood in a
   dispatch office at 6am.
2. Specific beats clever. One concrete number beats three adjectives.
3. Short sentences. No stacked qualifiers.
4. Never fake familiarity. No "Hope you're doing well!"
5. One clear ask per message.

## Banned words
synergy, leverage (as verb), solution, seamless, cutting-edge, revolutionize,
"quick call", "pick your brain", circle back

## Per channel
### `email_cold`
- Subject: lowercase, ≤6 words, no clickbait. Body ≤120 words. One proof point,
  one ask. No links in first touch.
### `email_followup`
- Reference the specific prior thread fact. ≤80 words. Never "just bumping".
### `linkedin_dm`
- ≤60 words, no pitch in first message, conversational question close.
### `discovery_call`
- SPICED order, listen ratio ≥60%, always book the next step on the call.
### `proposal`
- Plain headings, price on page one, no legalese in the body.

## Pre-write checklist
- [ ] Would the buyer's ops manager forward this without embarrassment?
- [ ] Is every claim traceable to content-library.md or public fact?
- [ ] One ask, clearly stated?
