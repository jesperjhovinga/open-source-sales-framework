# Example-Corp — Demo Org Context

A fully fictional company used to demonstrate the framework. Every surface is
filled with plausible dummy data so you can run any skill end-to-end before
creating your own context. Nothing here refers to a real organization.

**Example-Corp** (fictional): a 45-person B2B software company in Austin, TX
selling **FieldPilot**, a field-service management platform for mid-size HVAC,
plumbing and electrical contractors, plus implementation services.
